# M5 轨迹与拟时序

> 所属 skill：paper-insight-reporter。模块索引与通用约定见 [../extraction-modules.md](../extraction-modules.md)。

## 触发信号

"To uncover the differentiation dynamics ..."、"we utilized CytoTRACE and Monocle"、"pseudotime"、"trajectory"、"developmental progression"、"transition from A to B"。

这类章节容易被当成中性描述，实际承载的是**方向性结论**（谁先谁后、谁变成谁），而方向通常是人为指定的。整节的证据强度取决于这一点。

## 必填字段

| 字段 | 要求 |
|---|---|
| 研究目的 | 抄原文原句 |
| 分析对象 | 哪些细胞进入分析，样本范围是什么 |
| 工具与输入 | 工具 + 版本 + 降维方法 + 可变基因选择方式 |
| **根的方向如何确定** | 拟时序树的根由谁指定、依据什么。**本模块最重要的一栏** |
| 是否用第一个工具的输出定义第二个 | 检查循环性。常见写法是"两个工具结果高度一致"，但其中之一参与了根或顺序的设定 |
| 沿轨迹的分子变化 | 差异基因与通路。须注明这是"把表达对拟时序做回归"的产物，与轨迹同源 |
| 轨迹与已有分组的对齐 | 哪个已有分组落在轨迹的哪一段 |
| 分化方向的常识校验 | 结论与既有模型（EMT、干性、去分化）是否一致；不一致时作者是否指出 |

## 交付格式

按 SKILL.md 的四个部分出。第 4 部分额外点出**方向性检查**与**自洽性检查**的结果。

## 格式样例

> 以下为**虚构示例**，仅示范输出格式，不对应任何真实文献。

**主要发现**

1. 作者用 CytoTRACE 与 Monocle2 分析全部 29 个上皮细胞簇。两者结果被表述为"高度一致"：一项打分低（标志物 X+）对应轨迹后期，打分高（标志物 Y+）对应早期。
2. 转移灶来源的癌细胞打分低于原发瘤，位于轨迹后期；作者据此提出转移瘤可能由原发瘤"渐进分化"而来。
3. 沿拟时序做差异分析，上调基因覆盖分化与转录调控、免疫调节、EMT、代谢与缺氧四类功能；富集通路以免疫调节为主。
4. 在分组层面，某一类来源的样本呈 P5 到 P2 的递进；另一个组的分化程度更低，被解释为早期亚群。

**方法与复现要素**

| 步骤 | 方法/工具 | 关键参数 | 输出 | 复现风险与看图限制 |
|---|---|---|---|---|
| 拟时序 | Monocle2 | 降维方法待 Methods 核对 | 轨迹 | 中 |
| 分化潜能打分 | CytoTRACE | — | 打分 | 低 |
| **定根** | 人工指定 | 依据"先验知识 + 打分预测"，**无量化准则** | 轨迹方向（Fig. 3a） | **最高** |
| 沿轨迹差异 | 未说明 | 对拟时序做回归，方法待核 | Fig. 3d | 高，属自洽产物 |
| 通路富集 | 富集分析工具 | 校正方法待核 | Fig. 3e | — |
| 组间比较 | 分组汇总打分 | 仅覆盖部分来源的样本 | Fig. 3f | 覆盖面窄，却用了 "conserved" |
| 看 UMAP 时 | — | — | Fig. 3a | 图上没有箭头，**方向不在图里** |
| 看散点图时 | — | — | Fig. 3b | 相关性由定根方式决定，不能读作独立验证 |
| 看拟时序热图时 | — | — | Fig. 3d | 轨迹由表达定义，热图属自洽产物 |

**逻辑张力与问题**

本节的核心问题是**方向由人设定**：轨迹工具输出的是无向图，箭头由根决定，而根是作者依据"先验知识 + 打分预测"人工指定的，既未说明先验具体指什么，也没做替代方向的敏感性对比。更麻烦的是循环性——该打分工具参与了定根，随后又被当作顺序的独立佐证。同一段内还存在方向矛盾：结论说转移细胞"更分化"，同时又说 EMT 基因上调、细胞获得间质样特性，后者是去分化方向；跨小节看，本节主张序贯模型（由原发瘤渐进分化而来），而讨论部分主张平行演化模型（早期播散、独立演化），全文未调和。此外，组间比较只覆盖部分来源的样本。
