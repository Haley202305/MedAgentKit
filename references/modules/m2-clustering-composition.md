# M2 分群与细胞组成

> 所属 skill：paper-insight-reporter。模块索引与通用约定见 [../extraction-modules.md](../extraction-modules.md)。

## 触发信号

段落出现 "we annotated / we identified ... cell types"、"we subdivided ... into ... subtypes"、"the distribution of cell proportions"、"exhibited higher proportions in ..."。典型形态：先说分成几级、每级多少群，再说哪些群在哪些样本里占比高，最后给一句原因。

## 必填字段

| 字段 | 要求 |
|---|---|
| 分群层级与数量 | 每级的名称 + 数量 + 命名规则。各节叫法不一致时两边都记 |
| 规模边界 | 细胞总数；最小与最大群的细胞数 |
| 分群动作 | 归一化、批次校正、降维聚类各做了什么。只记动作，参数留待 Methods 核对 |
| 注释依据 | marker 的使用方式；对照的外部图谱或数据库 |
| 注释可信度证据 | 内部对照（如组织特异性细胞类型）+ 外部比对 |
| 组成分布发现 | 先说分析维度，再逐条记"哪些群在哪些样本里高或低"。注意区分完整列举与举例 |
| 占比差异的统计 | 有无 P 值、检验方法、多重比较校正 |
| 作者解释 | 标注为推断 |

## 交付格式

按 SKILL.md 的四个部分出。第 3 部分需覆盖分群动作与注释依据；第 4 部分额外点出**层级矛盾**——同一批群是否在不同章节被叫成不同级别。

## 格式样例

> 以下为**虚构示例**，仅示范输出格式，不对应任何真实文献。

**主要发现**

1. 512,340 个细胞经批次校正后，用 canonical marker 注释出 21 个 major cell type、38 个 subset，再细分为 140 个亚型（编号 C001-C140）；最小与最大群分别为 63 与 18,204 个细胞。
2. 作者用组织特异性细胞类型作为注释可信度的内部证据：某器官固有细胞只在对应组织出现；并把注释与两个公开图谱做了定性比对。
3. 组成分布按取样部位统计。作者举例：上皮类群在两类转移灶中占比更高；淋巴类群在原发瘤中更高。
4. 作者对上述分布的解释是"转移灶形成了免疫逃逸的微环境"。属推断，无数据支撑。

**方法与复现要素**

| 步骤 | 方法/工具 | 关键参数 | 输出 | 复现风险与看图限制 |
|---|---|---|---|---|
| 整合 | 归一化 + 批次校正 | 参数待 Methods 核对 | Fig. 1c | 参数不在本节 |
| 聚类 | 无监督聚类 + UMAP | resolution 待核 | Fig. 1d | 亚群 resolution 按目视调整 |
| 注释 | canonical marker + 外部图谱 | 定性比对 | Fig. 1e | 无定量一致性指标 |
| 组成分布 | 比例统计 | 维度为取样部位 | Fig. 1f | 占比差异未给 P 值 |
| 看 UMAP 时 | — | — | Fig. 1d | 坐标轴无单位，点密度受采样影响 |

**逻辑张力与问题**

占比差异完全没有统计量，而分布结论用的是 "such as"，属举例而非完整列举；外部比对只有 "consistent annotation" 这类定性表述。更关键的是**层级矛盾**：Results 写 "21 major cell types / 38 distinct subsets / 140 subtypes"，而 Methods 的分型段写成 "each of 38 major cell types"——同一批群在不同章节被叫成不同级别。引用该文的分型结论时必须先厘清是哪一级。
