# M4 独立维度刻画与分组互证

> 所属 skill：paper-insight-reporter。模块索引与通用约定见 [../extraction-modules.md](../extraction-modules.md)。

## 触发信号

"To establish a framework for ..."、"we used <tool> to detect / infer ..."、"we calculated <metric> across ..."、"this observation aligns with ..."。典型形态：引入一个与主分析不同的数据维度（基因组、表观、蛋白、空间），先刻画总体格局，再做组间或配对比较，最后把结果挂回已有分组。

这类章节的产出常被后文当作前提使用（"框架"一词就是信号），推断强度必须在这里标清楚。

## 必填字段

| 字段 | 要求 |
|---|---|
| 本节在全文中的功能 | 为什么放在这个位置、为后文哪一部分服务 |
| 分析对象与输入 | 哪些细胞或样本进入分析 |
| 方法与性质 | 工具 + 版本 + 参数；**必须注明是"实测"还是"从其他数据推断"** |
| 参考对照 | 推断类方法的前提（如 CNV 推断需要正常参考细胞）。缺失直接记为风险 |
| 总体格局 | 规模、组间整体差异 |
| 组间与配对比较 | 比较了哪些组、是否配对、方向如何 |
| 自定义量化指标 | 论文自造的指标（熵、指数、score）：定义、算法、取值范围。定义缺失即为复现风险 |
| 差异特征分类 | 差异特征怎么分组、分了几组、每组含义 |
| 与主分组的互证 | 结论挂到哪个已有分组上，是支持、矛盾还是无关 |
| 反向结果的处理 | 与预期相反的结果是什么、作者如何解释、该解释能否被本数据证伪 |

## 交付格式

按 SKILL.md 的四个部分出。第 4 部分额外点出**交叉分组检查**结果——本节产生的新分组是否与全文其他章节的分组互不兼容。

## 格式样例

> 以下为**虚构示例**，仅示范输出格式，不对应任何真实文献。

**主要发现**

1. 作者用 inferCNV 从上皮细胞的表达谱**推断** CNV，把 128,400 个上皮细胞聚成 60 个 CNV 群；不同肿瘤之间的 CNV 格局不同，呈癌种或来源特异。
2. 配对样本比较显示：原发瘤的 CNV 分数显著高于癌旁；某一类转移灶的 CNV 分数**低于**对应原发瘤；而另一类转移灶方向相反。
3. 以样本内各 CNV 群的细胞占比计算"异质性指数 H"：P5 高于 P1、P2。
4. 差异 CNV 基因被分为三组，其中一组富集于免疫相关通路，另一组富集于肿瘤内在的代谢与转录调控通路。

**方法与复现要素**

| 步骤 | 方法/工具 | 关键参数 | 输出 | 复现风险与看图限制 |
|---|---|---|---|---|
| CNV 推断 | inferCNV | 滑窗、阈值等参数待 Methods 核对 | 推断 CNV 谱 | **正常参考细胞未说明**；属表达推断，非实测 |
| CNV 聚类 | 基于 CNV 累积分聚类 | resolution 未给 | 60 个 CNV 群（Fig. S2a） | — |
| 配对差异 | 配对比较 | 检验方法待核 | Fig. S2d | — |
| 异质性指数 H | 自定义指标 | **无定义、无公式** | Fig. S2e | 复现风险最高 |
| 差异基因分组 | 未说明 | 分组标准待核 | Fig. S2f | — |
| 看 CNV 热图时 | — | — | Fig. S2a | 色标是推断的增益/缺失，不是实测拷贝数 |
| 看 UMAP 时 | — | — | Fig. S2b | 坐标轴无单位，"更分散"是目视判断 |

**逻辑张力与问题**

本节最需要注意的是**反向结果被同一套叙事吸收**：一类转移灶的 CNV 低于原发瘤，被解释为"转移经过选择、变得更同质"；另一类相反，被解释为"更复杂的基因组演化"。两个相反方向都能被"动态演化"容纳，而这组数据无法区分这两种解读与"样本间技术差异"等替代解释。其次，"CNV 分数"来自表达推断，正文却用 genomic instability 这类实测口径的词描述。另需注意**交叉分组**：异质性指数把组分成 {P5, P1} 与 {P2, 其他}，而免疫状态把组分成 {P5, P3} 与 {P1, P2}，两条分组线不一致，说明分组的"阶段"排序在不同指标下并不稳定。
