# M8 空间与实验验证

> 所属 skill：paper-insight-reporter。模块索引与通用约定见 [../extraction-modules.md](../extraction-modules.md)。

## 触发信号

"spatial transcriptomic deconvolution"、"UCell-based enrichment"、"multiplex immunofluorescence"、"colocalization"、"spatial support"、"further supported by"、"validated by"。

这类章节的作用是给前面的预测提供独立证据。问题在于：**"验证"一词覆盖的证据强度差别极大**——空间共定位、蛋白共表达、功能扰动是三件不同的事，而论文常用同一个"验证"把它们打包。本模块的任务就是把它们拆开。

## 必填字段

| 字段 | 要求 |
|---|---|
| 验证对象 | 要验证前面哪一个预测或结论 |
| 验证手段与层级 | 空间转录组 / 多重免疫荧光 / 功能实验；各自能证明到哪一步 |
| 队列与样本 | 哪些癌种、多少例、是否同一患者配对、比较的是原发还是转移 |
| 队列与主分析的匹配度 | 验证队列的癌种与部位，是否与主分析中该分组的样本来源一致 |
| 测量方式 | 空间：反卷积方法与打分方法；免疫荧光：抗体、成像参数、定量方式 |
| 定量指标 | 实际测的是什么量。"共定位""互作"这类词对应的真实测量往往不是它们字面的意思 |
| 统计 | 检验方法；配对设计是否用了配对检验；重复单位是样本还是视野 |
| 结论边界 | 该验证能支持到哪一步：物理可能性，还是功能与因果 |
| 作者自陈的局限 | 作者是否主动说明"这是共定位而非功能"。有则记下原句，这是作者诚实的证据 |

## 额外交付：两节固定检查

**验证层级检查。** 逐条把"能证明的"与"被写成证明了的"分开。同一节里如果出现"预测"与"验证"混排，明确指出哪些结论仍停留在预测层。

**测量—概念错位检查。** 论文使用 interaction、communication、recruitment 这类词时，回查它实际测的是什么量。最常见的错位是用荧光强度代表细胞接触，用共定位代表信号传递。

## 交付格式

按 SKILL.md 的四个部分出。第 3 部分的"复现风险与看图限制"列须写明每条证据的层级与真实测量对象；第 4 部分点出验证层级与测量—概念错位的结论。

## 格式样例

> 以下为**虚构示例**，仅示范输出格式，不对应任何真实文献。

**主要发现**

1. 用空间反卷积与基因集打分显示某两类细胞在癌旁组织中显著共定位；多重免疫荧光进一步显示这两种细胞在该区域的邻近程度强于转移灶。
2. 免疫荧光显示调节性 T 细胞与肿瘤细胞的"互作"在转移灶中强于原发灶。
3. 一套"免疫缺陷无差异、免疫重建有差异"的平行实验被用来把候选分子的作用定位到免疫依赖：免疫缺陷模型中敲低组与对照组无差异；免疫重建模型中敲低组肿瘤显著更小。
4. 作者在描述共定位时主动写明：该观察反映的是空间共定位，而非直接的配体-受体功能结合。

**方法与复现要素**

| 步骤 | 方法/工具 | 关键参数 | 输出 | 复现风险与看图限制 |
|---|---|---|---|---|
| 空间打分 | 排序型基因集打分 | 每亚型 top500 基因 + 经典 marker | Fig. 6b | 基因集构造参数多，未见敏感性分析 |
| 空间反卷积 | 基于参考的单细胞反卷积 | 以整合 scRNA-seq 为参考 | Fig. 6b | 结果是估计值，非观测 |
| 多重免疫荧光 | 多标免疫荧光 + 成像 | 抗体、成像倍数、视野数待 Methods 核对 | Fig. 6c、6d；Fig. S7 | **Methods 内部可能不一致**（如视野数），需逐条核对 |
| 荧光定量 | 图像软件测感兴趣区强度 | **非配对检验** | Fig. 6d | 队列为同一患者配对样本时，应使用配对检验；未用会高估显著性 |
| 验证队列 | 待核 | — | Fig. 6c、6d | **队列癌种与主分析中该分组的样本来源可能不匹配**，须逐个核对 |
| 功能实验 | 免疫缺陷 vs 免疫重建平行模型 | 各组样本量待核 | Fig. 6f-6i | 样本量通常很小；未说明随机化与盲法 |

**逻辑张力与问题**

本节的证据全部是间接的：空间给共定位，免疫荧光给荧光强度，功能实验给的是"免疫依赖"这一层结论——比纯预测强，但仍不是"某条配体-受体通路在起作用"的直接证据。要写进交付的重点有两个。**验证层级**：逐条区分"物理上可能""免疫依赖""功能与因果"三档，作者若主动写明局限（如"这是共定位而非功能"），把原句记下。**测量—概念错位**：所谓"两种细胞互作增强"，实际测的往往是感兴趣区内的平均荧光强度，不是细胞接触；写进交付时要点明这一点。另外须核对配对设计与所用检验是否匹配，以及验证队列的癌种是否与主分析中对应分组的样本来源一致。
