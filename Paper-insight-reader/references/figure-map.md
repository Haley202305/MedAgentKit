# 图表映射与复现要素

每个模块交付都必须包含这两张表。它们解决两个问题：**这条结论是从哪张图读出来的**（看图说话），以及**这套分析怎么重做一遍**（复现）。

## 图表映射表

| 图/表 | 图型 | 这张图能支持的判断 | 这张图不能支持的判断 | 本段哪些结论来自它 | 看图要点 |
|---|---|---|---|---|---|

填写要求：

- "本段哪些结论来自它"要一一对应到字段表里的具体结论，不要写"这一段的内容"这种笼统说法
- 一条结论如果没有对应图表，在表里单列一行，图号写 `无`，并注明"仅正文陈述，无图支撑"——这类结论的证据等级天然更低
- 一张图支撑多条结论时合并单元格，不要重复抄图型

## 复现要素表

| 分析步骤 | 输入 | 工具/包（含版本） | 关键参数 | 输出图型 | 代码/数据可得性 |
|---|---|---|---|---|---|

填写要求：

- 结果部分通常不写工具与参数，此表先按结果部分的描述填，工具与参数留 `待 Methods 核对`，阶段 2 再回填
- "代码/数据可得性"查 Data Availability 与 Code Availability：有 accession/GitHub 就写具体编号，没有就写 `未提供`
- 关键参数缺失本身就是复现风险，要在缺口清单里同步记一条

## 图型能力对照

填表时按此对照判断"能支持/不能支持"。这张表的作用是防止把图能说的话说过头。

| 图型 | 能支持的判断 | 不能支持的判断 | 看图要点 |
|---|---|---|---|
| 桑基图（Sankey） | 上游分组的**样本或细胞**如何分配到下游分组；组成与流向 | 具体的比例差异大小、统计显著性、机制。流向粗细是数量级，不是比例 | 每个节点的单位是样本还是细胞；流量粗细；左右两端的分组定义 |
| 热图（相关矩阵） | 矩阵层面的数值高低、分块结构 | 为什么高或低、因果、非线性关系 | 行/列注释条；色标范围；是否做了缩放，缩放会抹掉绝对值 |
| 热图（表达矩阵） | 每个群的特征基因及相对高低 | 绝对表达量（若已缩放）；统计显著性 | 是否 z-score 标准化；色标是否对称 |
| 层次聚类树 | 分组数量与边界 | 稳定性。除非给了 bootstrap 支持率或 ARI，否则"树切几刀"是主观的 | 分支高度代表距离；切点位置；有无注释条佐证 |
| 箱线图 | 组间分布差异（中位数、离散度、离群点） | 方向性机制；因果 | 检验方法、是否配对、P 值标注位置 |
| 小提琴图 / 山脊图 | 表达或分数的分布形状 | 统计显著性（除非明确标注） | 是否叠加了组间检验 |
| UMAP / tSNE | 降维空间中的邻接关系与分群 | 距离的绝对含义；细胞数量比例；机制 | 坐标轴无单位；点密度受采样与下采样影响，不能当比例读 |
| 点图（dot plot） | 富集结果：大小=基因数，颜色=显著性 | 效应量方向的细节 | 明确 size 与 color 各代表什么；P 值是否校正 |
| 火山图 | 单个特征的差异倍数与显著性 | 通路层面的结论（需下游富集） | 阈值线；logFC 与 P 的联合判读 |
| Kaplan-Meier 曲线 | 分组生存差异 | 因果、机制、多因素混杂 | 风险表；随访时长；删失；log-rank 是否双侧 |
| 弦图 / 配体受体热图 | 细胞类型间**预测**互作强度 | 真实物理接触、功能 | 显著性阈值；是否做了置换检验；预测与验证要分开写 |
| 多重免疫荧光图 | 蛋白层面的空间共定位 | 功能、因果 | 放大倍数与比例尺；定量方法与视野数；配对设计是否用了配对检验 |
| 空间转录组点图 | 空间分布与共定位 | 单细胞分辨率 | spot 分辨率；是否做了反卷积；与 scRNA-seq 的关系 |
| 饼图 / 堆叠柱状图 | 构成比 | 绝对数量；组间差异显著性 | 分母是什么 |

## 复现风险提示

出现以下任一情况，在缺口清单里明确记一条：

- 只写"根据稳定性/分离度"就定了分组数，没有量化指标
- 用了单细胞数据的比例做聚类，但没说明如何处理样本间细胞数差异
- 引用了外部数据集或数据库做验证，但只给定性结论、没有一致性指标
- 关键参数（阈值、resolution、迭代次数、cutoff 选择方法）在 Methods 里找不到
