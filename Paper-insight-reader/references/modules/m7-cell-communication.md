# M7 细胞通讯与配体-受体推断

> 所属 skill：paper-insight-reporter。模块索引与通用约定见 [../extraction-modules.md](../extraction-modules.md)。

## 触发信号

"cell–cell communication"、"cell–cell interaction"、"ligand–receptor (LR)"、"interaction strength"、"chord diagram"、"CellPhoneDB"、"recruitment score"。

这类分析的输出是**预测**，不是观测。它由表达量与预设的 LR 数据库推算而来，既不代表两个细胞真的接触，也不代表信号真的传递。整节的解释力取决于作者是否把这条界限讲清楚。

## 必填字段

| 字段 | 要求 |
|---|---|
| 分析对象 | 哪些细胞类型或亚型之间做互作推断 |
| 工具与版本 | CellPhoneDB 等；本节未说明的，标注"本节未给，去 Methods 核对" |
| 关键参数 | 表达阈值（如 ≥20% 细胞表达配体或受体）、置换次数、显著性阈值 |
| 推断性质 | 明确写出这是**从表达推断**，并记下作者有无实验验证 |
| 关键互作对 | 涉及哪些 LR 对与哪些细胞；本节只点名了几个就只记几个 |
| 自定义指标 | 如"招募分数"这类论文自造的量：定义、算法、取值范围。无定义即为复现风险 |
| 组间比较 | 不同分组之间的互作差异 |
| 验证层级 | 空间共定位、蛋白、功能实验各自提供了什么级别的证据，与预测分开写 |
| 作者解释 | 标注为推断 |

## 交付格式

按 SKILL.md 的四个部分出。第 3 部分的"复现风险与看图限制"列须写明推断性质；第 4 部分点出**预测与验证的界限**，以及机制链上有无任何一环被直接检验。

## 格式样例

> 以下为**虚构示例**，仅示范输出格式，不对应任何真实文献。

**主要发现**

1. 用细胞通讯推断工具比较四个分组的互作模式，发现各组差异明显：某一组以免疫细胞与内皮细胞之间的强通讯为特征，另一组以髓系细胞为中心，第三组以调节性 T 细胞为核心，第四组几乎没有免疫与非免疫细胞之间的显著互作。
2. 某一亚型高表达趋化因子 X 及其家族成员，表达量在多数分组中显著高于同类的其他亚型。
3. 互作分析显示该亚型与调节性 T 细胞的互作在同类亚型中最强，涉及 X 与其受体的多组配体-受体对。
4. 作者自建的"招募分数"显示该亚型招募调节性 T 细胞的潜力最高。
5. 作者据此提出机制链：该亚型在免疫抑制型分组中招募调节性 T 细胞，促成免疫耐受与免疫逃逸，最终导致更差的生存结局。

**逻辑张力与问题**

本节的互作结论全部来自表达推断：弦图给出的是预测强度，招募分数是无定义的自定义指标，两者都不构成"两个细胞实际接触或招募"的证据。要写进交付的重点是**预测与验证的界限**——如果后文有空间共定位或蛋白证据，要指出它证明到哪一步；如果没有，整条机制链就停在预测层。本案中该链的每一环都未获直接检验：**生存趋势不显著、互作为预测、招募分数无定义**，三者叠加才得出"招募 → 免疫耐受 → 预后更差"，而链上任何一环都没有独立证据。
